# Helm: history-conditioned return critic

Poseidon v0.6 adds an independently fitted, CPU-local return critic. It carries observed history and realized prediction errors without changing Tidal's trained reset protocol, the default core policy, pretrained language component, or TidePool dynamics. It is an experimental opt-in component, not a claim of safe policy improvement or reproduced upstream performance.

## Architecture and interfaces

`poseidon/helm.py` owns `HelmConfig`, `HelmCritic`, training, JSON persistence and feature state. A seeded frozen echo-state reservoir combines current observation, the preceding executed action and the realized difference from Tidal's preceding next-observation forecast. Ridge readouts predict six action returns under frozen core continuation at horizons 4 and 16. Fit observation-only, history without innovation and history with innovation families; use episode bootstrap heads and a disjoint selection partition. Select on forecast error, requiring meaningful improvement over the observation-only baseline. Calibration uses disjoint episodes and complete family-specific scoring pipelines. Episode maxima provide descriptive overestimation radii; they are not confidence or safety guarantees.

Public contract: `HelmCritic.fit(core, *, train_seeds, selection_seeds, calibration_seeds, anchors_per_episode=8, max_steps=96, config=None, progress=None)` returns `(critic, receipt)`. `progress(event)` receives structured phase/episode counters and may raise to cancel. `critic.save(path)`, `HelmCritic.load(core,path)`, `critic.reset(scarcity=1.0,max_steps=96)`, `critic.plan(observation, *, mode="selected")`, and `critic.act(observation)` support inference. `plan` is the state-advancing decision call; `act` calls it once and caches `last_decision`. Modes are `selected`, `observation`, `no_innovation`, `yoked`, and `ungated`. Yoked errors come from a deterministic frozen training-only error schedule and have separately calibrated radii. Decisions contain action, policy_action, proposed_action, overridden, mode, family, per-horizon forecasts/advantages/radii, support distance, margin, fallback reason, step and history/error diagnostics. Core bindings and source/world fingerprints are persisted. Inference consumes observations and executed-action predictions only, never simulator state or future labels.

Calibrated overrides require both horizons to exceed their family-specific radii and margin, training support and physical action admissibility. There is no depletion bypass. Insufficient remaining horizon, changed core weights, absent support or invalid input abstains or rejects explicitly. Ungated is a labeled diagnostic control. Artifacts validate shape, finiteness, partitions, bounds and binding; bounded stable reads parse only the bytes actually hashed.

`poseidon/helm_experiment.py` owns a frozen paired experiment and weightless verification. `run_helm_experiment(core,critic, *, seeds,max_steps=64,scarcity=1.0,anchor_interval=16,progress=None)` returns a receipt with trajectories for policy and each Helm mode. Controller state resets per episode. At regular anchors and every override, record actual six-action 4/16-step branches, continuation actions, executed decision and realized paired returns. `verify_helm_receipt(receipt)` reconstructs TidePool and recorded actions without core/model weights, rejects incomplete/tampered pairs and branch returns, and returns replay counts. `helm_risk_coverage(receipt)` reports predeclared descriptive margin thresholds, regular versus override anchors, adverse interventions and no-exposure rows. Do not use evaluation labels to silently choose deployment settings. Complete episode outcomes include paired win/tie/loss and leave-one-seed-out influence. Training/selection/calibration/evaluation seed episodes remain disjoint. Realized branch gains are frozen-core continuations, not full adaptive-policy causal guarantees.

`poseidon/jobs.py` owns bounded durable cooperative jobs. `ExperimentJobs(output_dir, *, producer, max_history=32)` supports `submit(kind,settings,work,timeout_seconds=300)`, `list()`, `get(id)`, `cancel(id)`, `close()`. `work(progress)` returns a bounded JSON-compatible result. A single worker runs jobs; queued/running/completed/cancelled/failed states, absolute deadlines, generation identity, atomic state files and interrupted-run recovery are explicit. Progress checks cancellation and timeout, including before publishing completion. Cancelled/partial results cannot become verified completed evidence. Poll/cancel stays responsive while runtime inference lock is occupied.

Root integration owns runtime, CLI, HTTP server, version, docs and release tools. Add Helm status/rollout, `fit-helm`, `helm-experiment`, `verify-helm`; retain existing synchronous routes and add `/api/jobs`, `/api/jobs/<id>`, `/api/jobs/<id>/cancel` for bounded Helm experiments. Jobs share the inference lock and source-change guard. Web UI provides Helm selection and progress/cancel/results. New implementation is independently written; no upstream code, weights or data are imported.

## Validation and acceptance

Test deterministic fitting and RNG/core preservation, partition rejection, artifact tampering, state reset, no-future feature construction, calibrated abstention, each control's calibration, changed-weight guard, cancellation/deadline/recovery, responsive status, strict model-free replay and tampered branch/pair rejection. Run actual CPU fitting and disjoint paired moderate/stress experiments; report negative or inconclusive findings. Source/runtime parity, browser desktop/mobile checks, full test suite and unchanged historical world/core hashes are required. The critic stays opt-in regardless of small-suite results. Publication requires package smoke and remote byte/revision verification.

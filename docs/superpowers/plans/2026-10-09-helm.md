# Helm implementation plan

> Execute this authorized implementation with independent agent scopes and evidence before completion.

**Goal:** Add and measure a CPU-local history-conditioned return critic, matched controls and cancellable experiments.

**Spec:** `docs/superpowers/specs/2026-10-09-helm.md`

**Architecture:** Frozen reservoir features plus ridge ensembles; frozen-core multi-horizon targets; strict observation-only inference; independent weightless branch replay; one durable cooperative job worker.

**Stack:** Python, NumPy, PyTorch core inference, existing HTTP server and vanilla JavaScript UI.

**Constraints:** Do not edit `poseidon/world.py`, core weights or default policy. Preserve history, active unrelated processes and source/version guards. Do not import upstream implementation or license-restricted materials. Reviews own distinct files; implementation scopes do not overlap.

## Tasks

1. Model agent: implement `poseidon/helm.py` and `tests/test_helm.py` against the spec. Establish deterministic tiny fit fixtures, meaningful tamper/state/binding tests, then fit code and persistence. Check actual target semantics, per-mode calibration and no hidden simulator access.
2. Experiment agent: implement `poseidon/helm_experiment.py` and `tests/test_helm_experiment.py`. Start with complete replay/tamper tests, strict trajectory and six-action branch contracts, then paired outcomes and descriptive risk/coverage. Verify without model weights.
3. Jobs/UI agent: implement `poseidon/jobs.py`, `tests/test_jobs.py`, and `poseidon/web/*`. Test cancellation, timeout, bounded queue/history and interrupted recovery. UI polls/cancels asynchronous Helm jobs and clearly labels critic/controls.
4. Root: integrate runtime, CLI and HTTP endpoints; add focused integration tests and research index; update version/docs after actual fit. Check strict inputs, single-work lock, stale source rejection and historical API parity.
5. Run focused tests, actual CPU fit and fresh disjoint moderate/stress suites. Independently verify complete receipts. Record model selection, forecast errors, episode outcomes, override exposure/harm and compute. Fix substantive failures; retain opt-in status.
6. Review across agent boundaries, full tests and browser checks. Freeze source; launch fresh runtime. If release scope completes, commit/push and build/smoke/upload/verify v0.6.0 using existing release authorization.

Review focus: history alignment with executed actions, training-only yoked schedules, selection/calibration/evaluation independence, no bypass of radii, explicit no-exposure reporting, cancellation before receipt publication, bounded stable artifacts, and existing world/core byte invariants.

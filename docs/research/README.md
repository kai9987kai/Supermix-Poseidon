## What the review changes in Poseidon

| Mechanism found | Independent implementation in this upgrade | Measurement boundary |
|---|---|---|
| Ghost's recurrent feedback from realized prediction mismatch; Expanse memory controls | Helm frozen history reservoir plus fitted multi-horizon return readouts; observation-only, no-innovation and yoked-error controls | Existing Tidal carry remains reset; a better forecast does not imply a better policy |
| Archimedes ridge bridges and component receipts; Supermix frozen partitions | Separate ridge ensemble, distinct fitting/selection/calibration/evaluation episodes and checkpoint binding | No donor transplantation or newly trained language model |
| MOLT yoked schedules; Prometheus selective memory intervention; MCO influence analysis | Training-only yoked errors, erased innovation, baseline family and leave-one-seed-out paired outcomes | Episode effects are simulator evidence, not biological memory evidence |
| Mnemorph bounded completed batches; TESSERA admission controls | Completed-only fitted artifacts and experiments; frozen model selection before fresh paired tests | No deployment promotion based on fitted loss or a public suite |
| Causeway event-keyed randomness; QuantumBot matched seed comparisons | Existing TidePool events retained; complete seed pairs and actual six-action 4/16-step branches | Paired branches follow the frozen core, not the future adaptive planner |
| REA stable reads and producer budgets; Odysseus/Mnemorph jobs | Bounded stable JSON reads, atomic job records, producer/generation identity, absolute deadline and cancellation | Cooperative Python threads cannot forcibly preempt a stuck native operation |
| NexusSearch retrieval filters; Odyssey observed topology | Training support abstention; existing observation-derived map stays available | Helm is a return critic; learned directed macro-navigation remains future work |
| NexusFlow typed adapters; universal-modder/SVideo export contracts; Flipper/Quibble interfaces | Retained capability/backend separation and explicit artifact contracts | No hardware emulation, game modification or OS integration added |

The choice is one measurable mechanism with controls, rather than collecting architecture labels. Remaining proposals are staged research, not implemented capabilities: directed navigation outcome models, full cross-carrier factorials, learned probe scheduling, symbolic template admission and decoded sprite export.

## Recent primary research

The cutoff is **9 October 2026**. Publication status and source versions matter; none of the following papers' reported scores or guarantees are Poseidon results.

- [Zero-Shot Reinforcement Learning under Partial Observability](https://arxiv.org/abs/2506.15446), RLC 2025, motivates testing history when observations omit state, reward or dynamics. Helm compares independently fitted history and observation-only families.
- [Future-Aware Recall](https://arxiv.org/abs/2609.34677), submitted 28 September 2026, is a recent preprint on training memory retrieval using later predictive usefulness. Helm uses future return labels during offline fitting; inference has only past/current observations. It does not implement FAR's video model or reproduce its evaluations.
- [DeepSPI: Reinforcement Learning in the Policy's Neighborhood for Safe Policy Improvement](https://proceedings.iclr.cc/paper_files/paper/2026/hash/0212b0dff7b4aa3bd8b8cc4ce24fd384-Abstract-Conference.html), ICLR 2026, motivates limiting policy changes around an incumbent. Helm's descriptive error radii do not satisfy or inherit that paper's guarantees.
- [Uncertainty-Aware Robotic World Model Makes Offline Model-Based Reinforcement Learning Work on Real Robots](https://arxiv.org/abs/2504.16680v3), revised January 2026, motivates checking temporal uncertainty instead of equating short-step fit with long-horizon control. Poseidon remains a synthetic environment, without robot validation.
- [Inference-Time Policy Optimization for Offline Reinforcement Learning with Differentiable World Models](https://arxiv.org/abs/2603.22430v2), revised May 2026, highlights the planning-cost trade-off. Helm uses a small fitted readout and records compute rather than adding unbounded online optimization.
- [SelectiveNet](https://proceedings.mlr.press/v97/geifman19a.html) and [Deep RL at the Edge of the Statistical Precipice](https://arxiv.org/abs/2108.13264) motivate descriptive benefit/harm versus intervention coverage and episode-level uncertainty. Sequential policy safety is a different claim; zero overrides mean no exposure, not proved successful intervention.

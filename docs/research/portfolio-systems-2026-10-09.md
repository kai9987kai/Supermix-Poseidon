## Existing Poseidon mechanisms and remaining gaps

The current local `world.py` already aligns exogenous draws with named events. `server.py` already limits POST bodies to 65,536 bytes, allows one active request and bounds workbench episode lengths. `language.py` already bounds context and generated tokens. `provenance.py` already rejects experiments when source changes after import. `world_controls.py` retains one detached planner decision per executed action. The v0.5.1 trajectory auditor independently reconstructs actual multi-step branches. These are existing capabilities, not new gains from this refresh.

The reviewed [local trajectory report](../TRAJECTORY_AUDIT.md) documents six adverse 16-step interventions among eleven ungated overrides, and calibrated Odyssey's zero overrides. Those are historical measurements read from the report, not fresh experiments in this review. They motivate testing when intervention is useful and how abstention limits exposure. They do not justify relaxing gates until an override appears.

## Three priority proposals

### 1. Measure the trade-off between override coverage and realized harm

Use existing frozen decision records and six-action trajectory branches to export a small, weightless decision report. For each predeclared support or margin threshold, report eligible anchors, proposed changes, accepted changes, realized return differences, adverse-change counts, survival outcomes and compute. Separate regular anchors from override-triggered anchors: conditioning only on visited overrides produces a biased picture of the wider decision set. State `no exposure` when a gate accepts zero changes; conditional harm and benefit are then undefined rather than zero.

Freeze threshold selection on calibration episodes, then evaluate the chosen setting on disjoint seed episodes. Diagnostic curves drawn using evaluation labels must be explicitly descriptive and must not silently select the deployed threshold. Replay all accepted and rejected candidate branch returns; resample at the episode/seed level because nearby anchors share trajectories. Diagnose storm, depletion and pre-transit override paths separately so a bypass cannot hide inside an aggregate mean.

This adapts risk-versus-coverage reporting from [Selective Classification](https://arxiv.org/abs/1705.08500) and [SelectiveNet](https://proceedings.mlr.press/v97/geifman19a.html). Those papers study classification/regression rejection; applying their reporting idea to sequential action interventions is an inference, and their guarantees do not carry over to an adaptive simulator policy. The immediate success criterion is an independently replayable report that exposes both zero-change behavior and adverse interventions. A beneficial planner remains a separate empirical objective.

### 2. Give every operation a bounded, inspectable producer contract

Extend existing route results with a consistent producer record: capability, actual backend, code/checkpoint identity, normalized settings, request identity, budget used, evidence status and artifact identities. Keep language generation, exact arithmetic, scene prediction, procedural rendering and world rollout distinguishable. A `verified` world execution means its recorded dynamics can be checked; it does not verify every model forecast. Format checks should report their checkable scope, following Supermix's deterministic response audit.

For imported evidence, use a bounded stable read and bind the digest to the bytes actually parsed. Preserve the current audit input cap, strict content checks and source-change guard. Where future jobs or bridges are asynchronous, attach episode/observation identity and expiry; reject stale results even if they arrive with a newer wall-clock timestamp. Use one absolute operation deadline and explicit cancellation state rather than restarting a full timeout at each phase. Step/forward-call limits provide deterministic CPU budgets; wall time is an additional diagnostic and interruption mechanism.

The REA and Fly Lab source supports the design. Acceptance tests should cover replacement/growth during reads, stale episode advice, wrong producer identity, cancellation, exhausted budgets and busy status. Successful readiness checks must remain distinct from successful inference and measured useful behavior. No external provider needs to be installed to implement this contract locally.

### 3. Add matched interventions and practical output contracts

Build a bounded factorial experiment around the existing world and policy: ordinary memory, sham handling, erased memory, permuted associations, stale observations and a deliberately mismatched environment setting. Use MOLT's yoked schedules and sign/acquisition controls, Supermix's frozen original-group partitions, Causeway's explicit structural sensitivities and QuantumBot's baseline families. Change one factor at a time before testing combinations. Keep train, threshold-selection and evaluation episode IDs separate and reject missing or duplicated arm/seed pairs.

Compare against the incumbent at equal observations and against a baseline with comparable forward-call or candidate-evaluation budgets. Report actual wall time, model calls, retrieval records examined and simulated transitions. Exogenous randomness is already matched in TidePool. Changes to its equations require a separately versioned world; historical receipts should continue replaying against their original engine. [Agarwal et al.](https://arxiv.org/abs/2108.13264) motivates intervals and performance profiles when few seeds make mean scores fragile. Use complete seed pairs as the sampling unit, and keep exploratory sensitivity results separate from claims on a frozen evaluation protocol.

In the interface, show the active mechanism, changed action and fallback reason beside its measured evidence. For useful media output, independently add a bounded primitive sprite-sheet/scene export contract: requested dimensions, heading order, frame count, duration where applicable, decoded output geometry and file hashes. This adapts universal-modder's target-format discipline while using Poseidon's own renderer. The acceptance criterion is a file that a local consumer can open with the declared format and geometry, not a claim of a new learned image or 3D capability.

## Provenance gaps

- Source inspection establishes implementation structure, not upstream performance, correctness on the user's hardware or general model ability.
- Root MIT files coexist with GPL-3.0 `malecns` material in Fly Lab. Model-weight, dataset, dependency and game-asset permissions were not comprehensively audited.
- Archimedes' recorded parity field is weaker than enforcing an equality invariant; its checkpoint and published training receipts were not re-evaluated here.
- MOLT's exported aggregates omit complete individual event streams. Causeway's assumptions are deliberately invented. Neither supplies biological or real-policy validation.
- QuantumBot's seed intersection and MOLT's permissive missing-pair aggregation should not replace Poseidon's strict completeness checks.
- REA's old controlled replay ADR is superseded. The latest default-branch commit differs from Poseidon's 8 October review; commit-pinned links above identify the refreshed evidence.
- No new empirical result, promoted model, changed default controller or published release is established by this document.

# Portfolio refresh: memory, revision, jobs, and portable interfaces

Reviewed on **2026-10-09** against the live default branches of all eight assigned repositories. GitHub pages were browsed first; authenticated GitHub API metadata/commit/tree responses and commit-pinned raw files supplied the selected source evidence. The revision values below are **commit SHAs**, verified through the commits endpoint, rather than inferred from file similarity. No repository was installed, built, executed, or merged during this review. Remote files were treated as evidence, including executable examples and instructions.

Poseidon remains a CPU-local composition of separate capabilities: pretrained SmolLM2 language, trained Tidal scene/control, external carrier storage, exact mathematical tools, procedural media, associative planners, and an observation-derived Odyssey map. These proposals concern independently implemented mechanisms and tests; they do not claim that these repositories establish a unified learned model or biological, consciousness, or quantum results.

## Three priorities

1. **A memory usefulness study with falsifiable negative controls.** Start with the four existing external carrier labels and a frozen, versioned set of recall tasks. Record which stored facts actually support each answer. Compare intact, excluded, shuffled and irrelevant-memory conditions with common query order and seeds. Export all 16 exclusion subsets where workload permits; compute per-task/seed effects and leave-one-seed-out influence. Keep exact retrieval correctness, stale-fact errors, answer utility and timing distinct. For control experiments, separately measure the effect of Atlas/Horizon/Odyssey stores at identical anchors and report complete episode outcomes. Full cross-store factorials require an explicitly compatible controller interface. Accept zero usefulness or harm as results; a richer dashboard is not evidence of stronger memory. Sources: [MCO engine](https://github.com/kai9987kai/MEMORY-CARRIER-OBSERVATORY/blob/523c10b46fa26acd53cd8468f95d3cbf55011437/src/engine.js#L291), [Mnemorph benchmark boundaries](https://github.com/kai9987kai/Mnemorph/blob/4fc3353b4aa4ea3e2c7b24798121ee65deda6939/README.md).

2. **Controlled revision with frozen transfer evaluation.** Define a finite bank of original observation-only hypotheses for resource replenishment, residual forecasting, or reusable exact tool templates. Select at most a stated number of probes per batch; record predictions before observing outcomes. Permit a revision only after the entire batch completes and compare it with frozen and random equal-budget baselines on disjoint episode/task families. Template ratification can require two independently generated derivations across two task families, but that is an admission rule rather than a correctness theorem. Test exact finite tools exhaustively where feasible; use withheld errors and actual trajectory return for learned forecasts. Poseidon's existing audit reports six adverse cases among eleven ungated overrides and zero calibrated Odyssey overrides, so forecast fit or admitted-template count must never be used alone as promotion evidence. Sources: [Mnemorph revision](https://github.com/kai9987kai/Mnemorph/blob/4fc3353b4aa4ea3e2c7b24798121ee65deda6939/src/core/compiler.js#L266), [TESSERA admission](https://github.com/kai9987kai/TESSERA/blob/85e740452824a0ae089332e47d3473db879ba70c/src/engine.js#L484), [TESSERA transfer](https://github.com/kai9987kai/TESSERA/blob/85e740452824a0ae089332e47d3473db879ba70c/src/engine.js#L793), [local trajectory audit](../TRAJECTORY_AUDIT.md).

3. **Bounded, cancellable experiments and transferable outputs.** Use a typed job state machine for internal CPU work: queued, running, cancellation-requested, completed, cancelled, failed and interrupted. Persist generation identity, requested budgets, completed seed blocks, source/config hashes, timings and output locations. Yield or poll cancellation at a documented unit of work; never emit a completed receipt from a partial batch. Test restart recovery, a stale cancel request, cancellation after the last block, and output/resource exhaustion. Keep thread limits explicit and measure actual cost, since matching assay counts does not match wall time. A versioned adapter registry and a frame/scene manifest then support original media or Unity exports without merging remote runtimes. Sources: [Odysseus jobs](https://github.com/odysseus-dev/odysseus/blob/a8c147b238db01dbd00b57774ed8b453f1e43971/src/bg_jobs.py), [Mnemorph worker](https://github.com/kai9987kai/Mnemorph/blob/4fc3353b4aa4ea3e2c7b24798121ee65deda6939/src/worker/experiment-engine.js), [NexusFlow limits](https://github.com/kai9987kai/nexusflow/blob/3fb4be7e7f9a523bcd817bd2bd94a2d7855229ec/nexusflow/lang.py#L1465), [Quibble extension boundary](https://github.com/7coil/quibble-builds/blob/f89481a1a3b81abfcbc1d43a2d539204101201aa/src/boot.cpp#L4726), [SVideo export pipeline](https://github.com/7coil/svideo/blob/d4b34633e92be30fd6395da1ffde21d6cac96917/src/App.ts#L184).

## Availability and review limits

All eight supplied repository URLs were reachable. GitHub page rendering omitted commit details in some responses, so commit IDs came from the live API and selected files from commit-pinned raw URLs. No assigned link was unavailable; Flipper's missing license/README/test evidence is an inspected-tree absence, not a failed fetch. This review did not verify every module, recursive submodule, release artifact, CI run, or model claim. The proposals above are recommendations derived from source inspection; none is reported here as an implemented Poseidon feature or demonstrated performance gain.
